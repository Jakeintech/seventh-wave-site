# seventh-wave-site

Public website for **Seventh Wave**, a sandcastle game for iPhone and iPad. *Dig walls. Hold back the sea.*

Will be live at <https://jakeintech.github.io/seventh-wave-site/> (GitHub Pages, from `main` /).

| Page | URL |
|---|---|
| Home (App Store marketing URL) | `/` |
| Support and FAQ (App Store support URL) | `/support.html` |
| Privacy Policy (App Store privacy URL) | `/privacy-policy.html` |

Keep these URLs as they are: App Store Connect points at them.

Plain HTML and one stylesheet. No build step here, no third-party requests, no analytics, no cookies.
The pages are generated by `scripts/publish_site.py` in the game repo; edit the source there, not the
output here. The screenshots are real captures from the game.
